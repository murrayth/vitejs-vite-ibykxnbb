# Projector Advisor – React Simple (no Next/Tailwind)

This is a minimal React + Vite version of the Projector Advisor so you can preview it instantly in CodeSandbox or StackBlitz.

## Run online (CodeSandbox)

1. Go to https://codesandbox.io/ and choose "Create Sandbox" → "Import from ZIP".
2. Upload this ZIP.
3. It will auto-install and start on a dev server. Open the browser preview.

## Run locally

```bash
npm install
npm run dev
# open http://localhost:5173
```

## Build

```bash
npm run build
npm run preview
```
